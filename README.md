# eStore (Toy BD)

PHP + MySQL দিয়ে তৈরি একটি বাংলা-প্রথম অনলাইন দোকান, সাথে পূর্ণ অ্যাডমিন প্যানেল।
কোনো ফ্রেমওয়ার্ক নেই: প্লেইন PHP, vanilla CSS/JS।

> A Bangla-first e-commerce store (PHP 8.1 + MySQL/MariaDB, no framework) with an
> admin panel, role-based permissions and a dynamic homepage section manager.

ডিজাইনের রেফারেন্স: [mfeex.shop](https://mfeex.shop/)

---

## ফিচার

**স্টোর (ক্রেতার দিক)**
- গ্লাস হেডার, লাইভ সার্চ সাজেশন, সাইড ড্রয়ার, মোবাইলে নিচের নেভিগেশন বার
- হিরো স্লাইডার ও সাইড কার্ড, ক্যাটেগরি, ডিলস, শপ পেজ (সার্চ, ফিল্টার, সর্টিং, পেজিনেশন)
- **ডাইনামিক হোম সেকশন**: অ্যাডমিন সেকশন যোগ/মোছা/ক্রম বদল করতে পারে (সর্বোচ্চ ৮, ন্যূনতম ২), প্রতিটিতে কতটি পণ্য দেখাবে তা ঠিক করা যায়
- প্রোডাক্ট ডিটেইলস (গ্যালারি, ভিডিও, রিভিউ, স্টক), কার্ট, উইশলিস্ট
- ক্যাশ অন ডেলিভারি চেকআউট, অর্ডার ট্র্যাকিং, কাস্টমার অ্যাকাউন্ট

**অ্যাডমিন প্যানেল** (`/admin`)
- পণ্য, ক্যাটেগরি, স্লাইডার, রিভিউ মডারেশন, কাস্টমার, স্ট্যাটিক পেজ, মেসেজ
- অর্ডার ম্যানেজমেন্ট (স্টক অটো সমন্বয়), পেমেন্ট, স্টক রিপোর্ট, Page Views রিপোর্ট
- রোল ও পারমিশন সিস্টেম (প্রতিটি মেনু আলাদা পারমিশনে সুরক্ষিত)
- দ্রুত পণ্য যোগ (মোবাইল-বান্ধব ফর্ম)
- ছবি আপলোডে অটো ক্রপ/প্যাড: পণ্য ৭০০×৭০০, হিরো ১২০০×৬৭৫, সাইড কার্ড ৬০০×৩৭৫

**নিরাপত্তা**
- সব POST ফর্মে CSRF সুরক্ষা (array/খালি টোকেন সহ), সেশন হার্ডেনিং
- আপলোডে `getimagesize()` যাচাই ও ৫MB সীমা
- প্রোডাকশনে ত্রুটির বিবরণ লুকানো, সংবেদনশীল ফোল্ডার `.htaccess` দিয়ে ব্লক

## প্রয়োজনীয় জিনিস

- PHP 8.1+ (`pdo_mysql`, `mbstring`; ছবি প্রসেসিংয়ের জন্য `gd` প্রয়োজন, না থাকলে ছবি ক্রপ ছাড়াই সেভ হয়)
- MySQL / MariaDB (পরীক্ষিত: MariaDB 10.6)
- Apache, `.htaccess` সাপোর্টসহ — [Laragon](https://laragon.org/) এ সহজে চলে (পরীক্ষিত: Apache + PHP 8.1/8.3)
- (ঐচ্ছিক) Node.js — ব্রাউজার-ভিত্তিক টেস্ট স্ক্রিপ্টের জন্য (পরীক্ষিত: Node 22, হেডলেস Chrome লাগে)

## লোকালে চালানো

1. রিপো ক্লোন করে প্রজেক্টটি ওয়েব-রুটে রাখুন (Laragon-এ `C:\laragon\www\estore`)।
2. একটি খালি ডাটাবেস বানান:
   ```sql
   CREATE DATABASE estore CHARACTER SET utf8mb4;
   ```
3. ডেমো ডাটাবেস ইমপোর্ট করুন (**শুধু খালি ডাটাবেসে** — ফাইলে `DROP TABLE IF EXISTS` আছে):
   ```bash
   mysql -uroot estore < database/estore_schema_demo.sql
   ```
4. `includes/config.php`-এর `DB CONFIG` ব্লকে নিজের হোস্ট, ডাটাবেস নাম, ইউজার ও পাসওয়ার্ড বসান।
5. একটি অ্যাডমিন ইউজার বানান (ডেমো ডাটাবেসে কোনো ইউজার নেই)। প্রথমে হ্যাশ বের করুন:
   ```bash
   php -r "echo password_hash('আপনার-পাসওয়ার্ড', PASSWORD_DEFAULT), PHP_EOL;"
   ```
   তারপর SQL-এ বসান (`role_id = 1` মানে Super Admin):
   ```sql
   INSERT INTO admin_users (role_id, username, password_hash)
   VALUES (1, 'admin', 'এখানে-উপরের-হ্যাশ');
   ```
6. ব্রাউজারে সাইট খুলুন (যেমন `http://estore.test`), অ্যাডমিন `/admin/login.php`।

PHP-র বিল্ট-ইন সার্ভারেও চালানো যায়: `php -S 127.0.0.1:8000`

> প্রথম রিকোয়েস্টে `includes/schema_v*.php` অটো-মাইগ্রেশন চলে এবং যা কিছু অনুপস্থিত তৈরি করে। একবার চললে আর কিছু করে না।

## প্রজেক্ট কাঠামো

```
index.php, shop.php, product_details.php, cart.php, checkout.php, ...   স্টোরের পেজ
admin/              অ্যাডমিন প্যানেল (পারমিশন-সুরক্ষিত)
includes/           config, হেডার/ফুটার, ইমেজ প্রসেসর, স্কিমা মাইগ্রেশন (v2–v7), হোম সেকশন helper
assets/             CSS (theme, components) ও JS
uploads/            পণ্য, স্লাইডার, লোগোর ছবি
database/           ডেমো ডাটাবেস ডাম্প
tools/              টেস্ট, ভেরিফাই ও সিড স্ক্রিপ্ট
```

বিস্তারিত সিদ্ধান্ত, নিয়ম ও পুরোনো সমস্যার সমাধান আছে [AGENTS.md](AGENTS.md) ও [CHANGELOG.md](CHANGELOG.md)-এ।

## টেস্ট

`tools/` ফোল্ডারে স্ক্রিপ্ট আছে (সাইট চালু থাকতে হবে)।

```bash
php  tools/test_home_sections.php                  # হোম সেকশন লজিক
php  tools/test_stock_flow.php                     # অর্ডার ↔ স্টক
node tools/test_csrf.js        http://estore.test  # CSRF
node tools/verify_hero.js      http://estore.test  # হিরো স্লাইডার (হেডলেস Chrome)
node tools/verify_see_all.js   http://estore.test  # "সব দেখুন" ও লেআউট
```

অ্যাডমিন-ভিত্তিক টেস্টে `ADMIN_COOKIE="PHPSESSID=..."` লাগে। পুরো তালিকা [AGENTS.md](AGENTS.md)-এর "টেস্ট টুল" অংশে।

## লাইভ হোস্টে (যেমন InfinityFree) তোলা

1. ফাইলগুলো আপলোড করুন, **লাইভের আলাদা DB credentials** সহ নিজের `includes/config.php` ব্যবহার করুন।
2. `config.php`-এ লোকালের `root` / খালি পাসওয়ার্ড কখনো রাখবেন না।
3. আপলোডের পর পরীক্ষা করুন: `/database/`, `/includes/config.php`, `/tools/` — তিনটিই `403` দেওয়া উচিত।
4. CSS/JS আপডেট না দেখালে `Ctrl+Shift+R`।

## নিরাপত্তা নোট

- ডাটাবেস credentials কখনো গিটে কমিট করবেন না। এই রিপোতে `includes/live.config.php`, `logs/` এবং `database/*.sql` (শুধু ডেমো ডাম্প বাদে) `.gitignore` করা আছে।
- `database/estore_schema_demo.sql` শুধু ডেমো ডেটা ধারণ করে (কোনো গ্রাহক/অর্ডার/অ্যাডমিন নেই)।
- অ্যাডমিন পাসওয়ার্ড শক্ত দিন। অ্যাডমিন লগইনে বারবার ভুলে আইপি-লক/ধীর করা আছে, অ্যাডমিন প্যানেলের "লগইন সুরক্ষা" মেনু থেকে নিয়ন্ত্রণ করা যায়।
